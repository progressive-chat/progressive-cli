Keeping the docs honest

The docs are generated from docs/features.json. Two node scripts (no dependencies) verify that the published page still matches the code it describes:

  • node docs/gen.mjs — resolves every feature anchor to a file + line and stamps the version/commit/build into docs/status.json.
  • node docs/check.mjs --remote <pages-url>/status.json — re-verifies the published page against the commit it was generated from, and reports drift against the working tree.

The CI runs the checker on every push and fails when the page would be stale. The site is served straight from the docs/ folder of the main branch (GitHub Pages, branch source) — it contains nothing but these docs, and deploys nothing else.
